# Proposal Site

A multi-screen Next.js presentation for a proposal-style interactive experience. It combines animated questions, balloons, photographs, a final message, optional music, and celebratory visual effects.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Motion
- Swiper
- SweetAlert2
- Canvas Confetti

## Features

- Timed introductory loader
- Guided question and response flow
- Photo and final-message screens
- Optional looping audio
- Responsive animated presentation

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Use `npm run build` and `npm start` for production mode.
